# Changelog

All notable changes to Qualgraph will be documented here.

## 0.1.0 - Unreleased

- Renamed package metadata from `analytify` to `qualgraph`.
- Added `qualgraph analyze` for the build, annotate, report, and export workflow.
- Added `python -m qualgraph` support.
- Added GitHub CI, release automation, and Dependabot configuration.
- Expanded installation, CLI, viewer, LLM workflow, configuration, and architecture documentation.
- Improved local viewer responsiveness, loading/error states, keyboard focus, overflow handling, and health checks.
